Python / Codex 學習路線

不用一次背完所有語法。先做小任務，讓 Codex 協助產生程式，再學會執行、檢查、修正與整理。

看完整 Python / Codex 書單取得 Prompt 範本

學習方式

這條路線適合完全初學者。不要先追求大型專案，先用 10 到 30 分鐘的小練習建立輸入、輸出、條件、迴圈、資料結構與網頁互動的基本感覺。

建議順序

  • 1. HTML / CSS 入門先做看得見的頁面，建立結構與版面概念。
  • 2. JavaScript 互動練習按鈕、表單、資料顯示與 localStorage。
  • 3. Python 小工具用 CLI、檔案、CSV、JSON 建立實作能力。
  • 4. Codex 協作流程學會描述需求、看 diff、跑測試與驗收結果。
