井字遊戲網路版原型

建立房間、複製邀請連結、輪流下 X 與 O。這是可部署在 GitHub Pages 的靜態版原型，適合先理解棋盤狀態、勝負判斷與分享連結。

靜態版說明

同一瀏覽器不同分頁可用房間代碼同步。跨裝置即時同步需要後端或即時資料庫，這版先保留純靜態架構。
