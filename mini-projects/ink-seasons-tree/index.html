Ink Seasons

水墨畫中的四季流轉

一棵古樹站在宣紙般的畫面中央，幾秒內依序經歷春芽、夏蔭、秋葉與冬雪。這是最小可用版，重點放在看得懂的四季變化與可操作的播放流程。

練習重點

用 SVG 畫出古樹，用 CSS 控制四季視覺狀態，再用 JavaScript 排出簡單時間軸。畫面是示意水墨風格，不追求真實筆觸模擬。

目前季節 春

按播放後會自動跑一輪春、夏、秋、冬。你也可以用單步切換觀察每一季的差異。

動畫控制

春天先長出淡綠新芽與花點，讓古樹從靜止畫面開始甦醒。

春：新芽與花點
夏：葉色變深
秋：橘葉飄落
冬：葉落與雪點
