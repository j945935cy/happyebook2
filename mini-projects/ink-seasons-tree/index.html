水墨畫中的四季流轉

以富士湖畔水墨圖作為主畫面，幾秒內依序經歷春花、夏綠、秋色與冬雪。這一版重點放在把同一張水墨畫套入四季流轉，並保留可操作的播放流程。

練習重點

主圖使用已轉成水墨風的富士湖畔圖，再用 CSS 疊加四季色調與粒子氛圍，用 JavaScript 排出簡單時間軸。

目前季節 春

按播放後會自動跑一輪春、夏、秋、冬。你也可以用單步切換觀察每一季的差異。

動畫控制

春天在富士湖畔疊上淡綠與花點，讓岸邊像剛醒來的水墨淡彩。

播放速度
