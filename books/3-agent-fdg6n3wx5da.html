以 3 個例子學會多 Agent 應用

從任務拆解、Agent 協作到成果驗收，實作 AI 工作流程

多 Agent 不是多開幾個聊天視窗，而是把複雜工作拆成清楚的任務，讓不同角色依照明確的輸入、輸出與驗收標準協作。 本書透過三個實例，帶你設計電子書製作、客服回覆與研究報告工作流，逐步掌握任務分工、交接依賴、品質檢查、人工核准與失敗處理。 讀完後，你將能判斷何時需要多 Agent，並把工作流程設計得更清楚、可追蹤、可驗收。
