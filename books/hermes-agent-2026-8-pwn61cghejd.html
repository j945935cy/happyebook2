Hermes Agent 實戰指南 (2026年8月更新版）

從安裝、快速入門到 10 個 AI 代理應用

本書寫給希望讓 AI 不只回答問題，還能實際操作檔案、終端、瀏覽器、程式碼與自動化流程的讀者。你不需要先學會打造 Agent，也不必是專業程式設計師；需要程式設計的章節會從可驗證的小型範例開始。 快速入門提供 Bash／WSL 與 Windows 原生 PowerShell 兩條路徑。第 8 章之後的完整伴隨實例以 Bash（Linux、macOS 或 Windows WSL2）作為主要可重現命令環境；Windows 原生讀者仍可使用 Hermes Desktop 與 PowerShell，但標成 bash 的區塊不可直接照貼。若希望逐章跟做全部實例，Windows 讀者應在第 3 章完成 WSL2 路徑。
