用 Codex 學 HTML：18 小時入門教材

從網頁骨架、語意標記、表單、可存取性到發布的實作課

《用 Codex 學 HTML：18 小時入門教材》是一本為 HTML 初學者設計的實作型電子書。本書以 18 個小時為學習節奏，從最基本的 HTML 文件骨架開始，逐步帶你認識標題、段落、清單、連結、圖片、表格、表單、語意化區塊、可存取性、metadata、響應式影像與發布前檢查。每一章都包含可參考範例、概念示意圖、範例截圖、練習任務、常見錯誤與驗收標準，適合想從零開始建立網頁基礎的人。這本書也加入 Codex 輔助學習的做法，協助讀者請 Codex 產生範例、檢查結構、改寫標記、找出錯誤，並逐步建立自己的個人作品介紹頁。
