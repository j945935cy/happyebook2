Pi Coding Agent 入門

從安裝、設定到程式碼與長篇文件實戰

Pi Coding Agent 是在終端機中運作的 AI 程式代理：你交給它一項任務，它讀取檔案、修改程式碼、執行指令，並依測試結果繼續修正。本書寫給會使用基本終端機、但初次接觸 AI 程式代理的讀者，從安裝、登入模型服務到限制工具權限逐步示範，並以三項可驗證的實戰貫穿全書——用測試驅動開發完成樂透小遊戲、建立 Flask JSON API、編輯一本五千詞以上的英文電子書。你不只學會下指令，更學會用 Git 差異與重新執行測試來驗收代理成果。附錄含指令速查表、六道練習題與術語表。全書指令皆於 Pi 0.84.2（2026-08）實測驗證。
