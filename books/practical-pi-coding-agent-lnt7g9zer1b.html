Practical Pi Coding Agent

Skills, Collaboration, and Model Evaluation

Asking an AI agent to “finish the work” is easy. Getting files you can inspect, steps you can repeat, and evidence you can trust takes a deliberate workflow. This practical guide introduces the Pi Coding Agent and distinguishes it from Oh My Pi, a separate fork. It shows you how to build and assess Skills, define multi-agent handoffs, choose models for specific tasks, and design rule-based routing without treating model output as proof of success. The final six chapters follow a book-production project from audience and outline through drafting, diagrams, review, a publication candidate, and long-term maintenance. Each chapter includes examples, operating guidance, common failure modes, checklists, and an offline exercise workbook. The book keeps documented behavior, local checks, and untested assumptions separate, so you can tell what the evidence supports. You do not need to be a programmer, but you should be comfortable using a terminal, reading command output, and managing files. Live model use requires your own provider account and may incur charges. Product commands, model availability, prices, and platform rules can change; verify them for your version and region.
