Codex CLI 入門

從安裝到完成第一個程式任務

想用 Codex CLI 協助修改程式，卻不確定它改了什麼、測試是否真的跑過？本書以一個小型待辦程式為練習主線，帶你從確認工作環境、安裝與首次啟動開始，逐步練習先唯讀盤點專案、寫清任務範圍與驗收條件、記錄 Git 基線，再讓 Codex 提出計畫並完成一項小型修改。接著，你會練習閱讀程式差異、執行測試、判讀失敗，並在結果不符合預期時安全停止或復原。重點不只是「怎麼下提示」，而是如何確認工作真的完成：模型的說法不等於檔案已修改，測試通過也只代表實際執行的檢查通過。書中透過逐步案例與最後的綜合演練，建立一套可檢查、可驗收、可復原的 Codex CLI 入門工作流程。適合想開始使用 Codex CLI、並希望把 AI 協助納入程式練習流程的讀者。完整跟讀需要可使用終端機、Git 與 Python 3 的環境；主要操作路線為 Linux、macOS 或 WSL2 的 Bash。Windows PowerShell 範例僅作環境對照，並非本書完整跟讀路線。範例素材與版本資訊請依書中指引取得及核對。
