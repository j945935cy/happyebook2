# Happy eBook 書籍管理後台 (admin.html) 使用說明

這份文件說明如何使用 `admin.html` 進行書籍的「新增、修改、刪除與排序」，以及如何將更新後的書單發布至網站上。

## 1. 開啟管理後台

因為這個後台是純靜態的前端程式，你可以用以下兩種方式開啟它：

- **方法 A（推薦）：透過本地伺服器開啟**  
  在終端機輸入 `python3 -m http.server 8765`，然後在瀏覽器網址列輸入 `http://localhost:8765/src/admin.html`。
- **方法 B：直接點擊檔案**  
  在資料夾中找到 `c:\ebooks\happyebook2\src\admin.html`，點擊兩下直接用瀏覽器（Chrome/Edge 等）開啟即可。

---

## 2. 介面與功能導覽

進入後台後，你會看到三大區塊：

### 🎯 頂部狀態列與搜尋篩選
- **數據儀表板**：快速查看目前「已上架」、「未上架」、「付費」、「精選」的書籍總數。
- **搜尋框**：輸入關鍵字（書名、作者、分類等）可即時過濾想找的書。
- **篩選按鈕**：點擊「全部 / 已上架 / 未上架」等按鈕，快速切換顯示的書單。

### 📚 書籍列表管理
每一本書會以卡片形式呈現，右側有以下快捷按鈕：
- **↑ 上移 / ↓ 下移**：點擊可直接改變這本書在書單中的排列順序。
- **上架 / 下架**：快速切換書籍的公開狀態（下架的書籍在前台完全不會顯示）。
- **編輯**：點擊後會彈出視窗，讓你修改書籍的詳細資料。
- **刪除**：將該書從清單中移除。

### 📝 新增與編輯書籍 (Modal 表單)
點擊右上角的「新增書籍」或列表上的「編輯」按鈕，會打開表單視窗：
- **書籍 ID (必填)**：請使用「英文小寫、數字與連字號(-)」。若你是「新增」，在填寫書名時系統會自動幫你轉譯產生一組 ID。
- **狀態勾選**：最上方可以勾選「已上架」、「列入精選書櫃」、「標示為熱門」。
- 填寫完畢後，點擊「儲存書籍」，你的變更就會立刻顯示在列表中。

## 3. 發布與儲存流程 (最重要)

⚠️ **注意：你在網頁上做的所有增刪改查，當下都只暫存在你「自己的瀏覽器」裡！**
要讓前台網站更新，請務必執行以下標準流程：

### 步驟一：匯出更新後的書單
當你完成所有編輯後，視線移到網頁右上角（搜尋框旁邊），點擊 **「下載 books.json」**。
瀏覽器會自動下載一個包含最新書單資料的檔案。

### 步驟二：覆蓋舊檔案
1. 把下載下來的 `books.json` 複製。
2. 貼上並**覆蓋 (取代)** 專案資料夾中的舊檔案：`c:\ebooks\happyebook2\src\books.json`
3. *(如果有新封面圖)*：把圖片放進 `assets/images/` 資料夾中。

### 步驟三：推送到 GitHub
打開你的終端機 (Terminal 或 PowerShell)，輸入：
```powershell
git add src/books.json
git commit -m "更新書單：新增/修改書籍資料"
git push origin main
```
等 GitHub Pages 背景執行約 1~2 分鐘後，讀者就能在網站上看見你剛更新的內容了！

## 💡 常見問題與除錯

**Q: 為什麼我用 VS Code 直接改 books.json，前台卻壞掉了？**
A: `books.json` 有非常嚴格的格式要求。如果有多個分類，必須用中括號寫成陣列格式，例如：`"category": ["證照學習", "AI 工具"]`。建議盡量使用 `admin.html` 進行新增與修改，後台程式會自動幫你轉換成不會出錯的正確格式。

**Q: 我在後台改了一半不小心關掉網頁，資料會不見嗎？**
A: 不會！後台有內建防呆機制，每次儲存時都會暫存一份在你的瀏覽器中 (localStorage)。下次打開 `admin.html` 時，會優先讀取你上次修改到一半的狀態。確認沒問題再點「下載 books.json」即可。

**Q: 我想要放棄剛才在瀏覽器裡亂改的狀態，回到跟 GitHub 上面一樣的原始書單怎麼辦？**
A: 你只要在瀏覽器的開發者工具 (F12) 的 Application > Local Storage 中，把名為 `happyebook_admin_books_v2` 的資料刪除，然後重新整理網頁，後台就會重新讀取你硬碟上那份原始的 `books.json` 了。
