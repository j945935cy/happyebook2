# Google Books 上架文案

## 書名

用 Codex 做出 10 個小作品 2

## 副標

地圖、動畫、穿搭、任務代理與飛行模擬實作入門

## 短簡介

這是《用 Codex 做出 10 個小作品》的第二本，帶初學者用 Codex 完成第二組純前端小作品，練習表單、地圖資料、動畫切換、圖片互動、鍵盤控制、遊戲邏輯與 Prompt 工具。

## 長簡介

已經用 Codex 做過幾個小作品，想再往前練習嗎？

《用 Codex 做出 10 個小作品 2》延續第一本的學習方式，繼續用小任務帶你練習 AI coding。這次的作品更接近可展示的小工具與互動頁，包含小吃店結帳程式、野狼 125 遊台灣、台南美食一日遊、嘉義美食一日遊、彰化美食一日遊、水墨畫中的四季流轉、Office Lady 穿搭學習、台灣簡易飛行模擬、星際射擊小遊戲與 Hermes Agent 任務代理產生器。

每一章都用固定流程說明：

- 這個作品要完成什麼
- 這章要學哪些觀念
- 第一次可以給 Codex 什麼 prompt
- Codex 可能會修改哪些地方
- 完成後要怎麼人工檢查
- 發現問題時要怎麼請 Codex 小步修正
- 還可以怎麼延伸練習

本書仍然維持初學者友善的限制：使用 HTML、CSS、Vanilla JavaScript，不加後端，不引入大型框架，並優先支援 GitHub Pages 靜態部署。讀者不需要一開始就懂完整網站架構，而是透過一個又一個小作品，練習把需求說清楚、看懂修改結果、檢查手機版與主要操作流程。

這本書的第二組作品會帶你練習更多互動情境：表單計算、資料陣列、站點切換、累計里程與預算、城市行程複製、圖片與季節狀態、穿搭場合切換、鍵盤事件、背景縮放、導航任務、射擊遊戲迴圈，以及把任務整理成可複製 Prompt 的工具設計。

本書重點不是讓 AI 取代學習，而是讓你建立穩定的 AI coding 工作循環：先縮小任務，再請 Codex 協作，接著自己檢查，最後針對問題提出修正要求。只要你願意照著步驟做，就能逐步完成第二組 10 個可操作的小作品。
