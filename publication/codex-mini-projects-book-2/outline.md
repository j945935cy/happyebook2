# 用 Codex 做出 10 個小作品 2

副標暫定：地圖、動畫、穿搭、任務代理與飛行模擬實作入門

作者：Happy eBook

## 書籍定位

這是《用 Codex 做出 10 個小作品》的第二本。第一本先帶讀者完成故事書、英文練習、抽籤、賓果、井字遊戲、電子白板、打磚塊、拉霸與 3D 摩天輪；第二本則進一步練習比較完整的互動作品。

本書仍然以初學者為主，使用 HTML、CSS、Vanilla JavaScript 與 GitHub Pages 可部署的靜態網頁，不引入後端、不使用大型框架。每章都用固定流程：先說明作品目標，再給 Codex prompt，接著檢查結果，最後用小修改任務練習修正。

## 讀者對象

- 已讀過第一本，想繼續做第二組小作品的人。
- 想用 Codex 練習地圖、動畫、資料切換、遊戲控制與任務工具的人。
- 想用純前端完成可展示作品的初學者、自學者、教師與親子共學者。

## 全書章節架構

## 第 1 章：第二本怎麼學

### 作品目標

建立第二本的學習方式，說明本書和第一本的差異。

### 學習重點

- 從單一功能進入多狀態互動。
- 從靜態頁面進入資料切換、動畫與遊戲控制。
- 繼續使用小任務、prompt、檢查、修正的流程。
- 理解為什麼仍然選擇純前端與靜態部署。

### 本章檢查點

- 讀者知道第二本會做哪 10 個作品。
- 讀者知道每章都會提供 prompt 與檢查清單。
- 讀者知道不需要先學會完整 JavaScript 才能開始。

## 第 2 章：作品 1：小吃店結帳程式

### 作品目標

做出一個可輸入餐點數量、計算小計與總金額的結帳頁。

### 學習重點

- 表單輸入與數字轉換。
- 用 JavaScript 讀取使用者輸入。
- 小計、總計與清除功能。
- 讓表格在手機版也能閱讀。

### 建議 prompt 任務

請 Codex 建立一個純前端小吃店結帳程式，包含餐點列表、數量輸入、小計、總金額與清除按鈕。

### 本章檢查點

- 數量改變後，總金額會同步更新。
- 數量為 0 時不會出錯。
- 手機版表格不會超出畫面。

## 第 3 章：作品 2：野狼 125 遊台灣

### 作品目標

做出一個繞台灣一圈的旅遊互動頁，逐站顯示景點、美食、里程、時間與花費。

### 學習重點

- 用陣列保存每一站資料。
- 用按鈕切換目前站點。
- 顯示累計里程、累計時間與累計花費。
- 讓地圖、路線與站點提示保持一致。

### 建議 prompt 任務

請 Codex 做一個「野狼 125 遊台灣」純前端小作品，從台北出發繞台灣一圈，逐站顯示景點、美食、累計里程、時間與花費。

### 本章檢查點

- 每一站資料正確切換。
- 累計數字會隨站點更新。
- 地圖上的縮圖與目前站點一致。

## 第 4 章：作品 3：台南美食一日遊

### 作品目標

做出一個台南美食一日遊互動頁，安排早餐、午餐、晚餐與點心。

### 學習重點

- 把旅遊資料整理成可維護的站點資料。
- 地圖路線不必直線，可以依一日行程需求安排。
- 顯示時段、店家、美食、預算與移動說明。
- 從「旅行一圈」改成「城市一日遊」。

### 建議 prompt 任務

請 Codex 以台南為主題，建立一個美食一日遊純前端小作品，包含時段、站點、美食、預算、地圖與路線切換。

### 本章檢查點

- 早餐、午餐、晚餐與點心都有安排。
- 地圖外形與城市主題一致。
- 手機版的下一站資訊不會離路線太遠。

## 第 5 章：作品 4：嘉義美食一日遊

### 作品目標

以台南美食一日遊為範本，改做嘉義版本。

### 學習重點

- 用既有作品當模板。
- 替換城市資料、站點、美食與文案。
- 保留原本可用的互動邏輯。
- 檢查複製後是否還殘留舊城市文字。

### 建議 prompt 任務

請 Codex 以「台南美食一日遊」為範本，新建「嘉義美食一日遊」，保留互動結構，但改成嘉義景點、美食、時段與預算。

### 本章檢查點

- 頁面標題、SEO、地圖、站點都改成嘉義。
- 不應殘留台南店名或台南文案。
- 小作品首頁有正確連到嘉義頁。

## 第 6 章：作品 5：彰化美食一日遊

### 作品目標

再用同一個美食一日遊架構，建立彰化版本。

### 學習重點

- 練習第二次複製範本。
- 比較台南、嘉義、彰化三個版本的共通結構。
- 修正手機版資訊距離與版面問題。
- 理解資料不同、互動邏輯相同的設計。

### 建議 prompt 任務

請 Codex 以「台南美食一日遊」為範本，新建「彰化美食一日遊」，改成彰化景點、美食、時段與預算，並檢查手機版版面。

### 本章檢查點

- 彰化頁能獨立開啟。
- 城市資料完整替換。
- 手機版下一站資訊與一日路線距離合理。

## 第 7 章：作品 6：水墨畫中的四季流轉

### 作品目標

做出一個水墨風互動動畫，讓畫面在春、夏、秋、冬之間切換。

### 學習重點

- 使用圖片、CSS 與 JavaScript 做狀態切換。
- 用按鈕控制季節。
- 用視覺元素表現四季變化。
- 練習把使用者提供的圖轉成作品主視覺。

### 建議 prompt 任務

請 Codex 做一個「水墨畫中的四季流轉」純前端小作品，以一張主圖為基礎，加入春夏秋冬四種狀態切換與對應文案。

### 本章檢查點

- 四季按鈕都能切換。
- 主圖不會被文字遮住。
- 季節提示文字清楚且不誇張。

## 第 8 章：作品 7：Office Lady 穿搭學習

### 作品目標

做出一個穿搭學習小工具，使用者可依場合模式切換穿搭圖與建議。

### 學習重點

- 用按鈕切換資料狀態。
- 依場合切換主圖。
- 顯示穿搭理由與搭配分數。
- 修正版面，避免標籤壓到圖片。

### 建議 prompt 任務

請 Codex 做一個 Office Lady 穿搭學習小工具，包含日常上班、重要會議、下班約會、週五休閒四種場合，點選場合時切換圖片與穿搭建議。

### 本章檢查點

- 四個場合都能切換圖。
- 主圖完整顯示，不裁切人物。
- 穿搭文字不會壓到圖片。

## 第 9 章：作品 8：台灣簡易飛行模擬

### 作品目標

做出一個以台灣地圖為背景的簡易飛行模擬，控制飛機轉彎、高度與速度。

### 學習重點

- 鍵盤事件：方向鍵、A、D。
- 高度改變時背景縮放。
- 速度影響背景移動感。
- 任務點、導航箭頭、到站紀錄與累計里程。

### 建議 prompt 任務

請 Codex 做一個台灣簡易飛行模擬小作品，以台灣地圖為背景，方向鍵控制轉彎與高度，A 加速，D 減速，並加入城市巡航任務。

### 本章檢查點

- 左右鍵能轉彎。
- 上下鍵能改變高度與背景大小。
- A/D 能改變速度。
- 飛到城市點附近會完成任務。

## 第 10 章：作品 9：星際射擊小遊戲

### 作品目標

做出一個簡單射擊遊戲，玩家控制飛船、發射子彈、擊中敵人並累積分數。

### 學習重點

- 遊戲迴圈。
- 玩家移動、子彈、敵人生成。
- 碰撞判斷與分數。
- 遊戲開始、結束與重玩。

### 建議 prompt 任務

請 Codex 做一個純前端星際射擊小遊戲，玩家可用鍵盤控制飛船移動與發射，敵人會出現，擊中後加分。

### 本章檢查點

- 玩家可以移動與射擊。
- 子彈擊中敵人會加分。
- 遊戲結束後可以重新開始。

## 第 11 章：作品 10：Hermes Agent 任務代理產生器

### 作品目標

做出一個任務代理 prompt 產生器，使用者輸入任務後，產生角色、目標、限制、流程與檢查規則。

### 學習重點

- 表單輸入與文字組裝。
- Prompt 模板設計。
- 複製輸出。
- 幫助使用者把模糊需求整理成可執行任務。

### 建議 prompt 任務

請 Codex 做一個 Hermes Agent 任務代理產生器，使用者輸入角色、任務目標、限制與偏好後，產生可複製的任務 prompt。

### 本章檢查點

- 輸入欄位能正確組成 prompt。
- 複製按鈕可用。
- 產出的文字有角色、目標、範圍、限制、流程與檢查規則。

## 第 12 章：整理第二組小作品集

### 作品目標

把第二組 10 個小作品整理成可發布、可維護的小作品集。

### 學習重點

- 小作品首頁排序與分類。
- 每個小作品回到首頁的連結。
- sitemap 與 SEO 基本資料。
- 手機版、連結、圖片與 JavaScript 檢查。
- GitHub Pages 靜態部署思維。

### 建議 prompt 任務

請 Codex 檢查第二組 10 個小作品，確認小作品首頁連結、各作品返回連結、手機版、SEO、sitemap 與 JavaScript 語法都正常。

### 本章檢查點

- 小作品首頁可連到 10 個作品。
- 每個作品都可返回小作品首頁。
- sitemap 有收錄新增頁面。
- 手機版沒有明顯重疊或超出畫面。
- 完成後可以作為第二本書的線上範例集。

## 全書固定章節模板

每個作品章節建議使用下列小節：

1. 作品目標
2. 這章要學什麼
3. 檔案位置

6. 完成後怎麼檢查
7. 發現問題時怎麼請 Codex 修正
8. 延伸練習
